- `[manual]` Fixed the **Mutation score** CI job, which had crashed on `TypeError: ts.parseConfigFileTextToJson is not a function` since TypeScript was bumped to 7.0.2 (#320) — TS 7 removed that API and `@stryker-mutator/core@9.6.1` (the latest release, so there is nothing to upgrade to) still calls it from its sandbox tsconfig preprocessor. Because `mutation.yml` is path-filtered it had **0 runs on `main`** after the bump, so the gate was silently offline on the trust-critical modules it exists to protect. Pointing `tsconfigFile` at an unresolvable path makes the preprocessor skip the removed call; that is a no-op here specifically because `tsconfig.json` uses neither `extends` nor `references`, and the config records that precondition so the workaround can be removed when Stryker ships TypeScript 7 support.
