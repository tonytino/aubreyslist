- `[manual]` Fixed the **Mutation score** CI job, which had crashed on `TypeError: ts.parseConfigFileTextToJson is not a function` since TypeScript was bumped to 7.0.2 (#320) — TS 7 removed that API and `@stryker-mutator/core` still calls it from its sandbox tsconfig preprocessor (10.0.0, the latest release, carries the identical call, so no published version fixes it). The failure hid in plain sight: the job's relevance step reports **success without running Stryker** whenever a PR touches no trust-critical file, so this required check kept going green while the gate was dead on `app/trust/**`, the dedup matcher, and the rate limiter — only a PR that actually touched those paths could expose it. Pointing `tsconfigFile` at an unresolvable path makes the preprocessor skip the removed call; that is a no-op here specifically because `tsconfig.json` uses no `extends` or `references` and its include/exclude/files entries all resolve inside the repo, and the config records that precondition so the workaround can be removed when Stryker ships TypeScript 7 support.
