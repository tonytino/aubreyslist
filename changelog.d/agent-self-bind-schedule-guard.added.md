- `[manual]` Added a guard (via the `block-self-bind-schedule` Claude Code plugin) that blocks agents from scheduling self-check-in wakeups on the same session (`send_later`, or `create_trigger` without `persistent_session_id`/`create_new_session_on_fire`). Those calls resend the full conversation history on every fire and can exhaust usage on long-lived sessions with no benefit over the reactive PR-activity subscription agents already use.
