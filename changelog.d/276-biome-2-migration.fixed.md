Enabled `css.parser.tailwindDirectives` so Biome's stricter CSS parser understands Tailwind v4's `@theme`/`@custom-variant`/`@variant` at-rules, which surfaced a real bug: `app/styles/app.css` was overriding the `dark` variant with the wrong directive (`@variant dark (...)` instead of `@custom-variant dark (...)`) — corrected per the current Tailwind v4 docs. Also removed four `noDelete` suppression comments that biome 2.x no longer flags, and applied three biome-suggested (verified type-safe) optional-chain simplifications.
