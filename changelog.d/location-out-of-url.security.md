- `[manual]` The visitor's coordinates no longer travel in the URL. `?lat=`/`?lng=` are gone from the browse search params: location now lives in route state for the life of the tab and reaches the server only as a rounded server-function argument, so it never enters browser history, a referrer header, a screenshot, or a shared link. Readings are rounded to 2 decimals (about 1 km, `coarsenCoords`) before they leave the browser, and nothing is written to device storage. A distance-sorted view still shares as a clean link: the recipient is anchored by their own location, not the sender's. Because SSR has no reading, the first paint anchors on the request's coarse IP location instead, and the client refetches inside a `startTransition` once the browser answers.
