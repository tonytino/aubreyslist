- `[manual]` A browser that blocks location for the site answers instantly with `PERMISSION_DENIED` and shows no prompt (iOS Safari with Location off for Safari, or a per-site Deny). The "Near me" sort used to read that as "you declined" and told you to enable location in your browser. It now checks the stored grant first (`navigator.permissions`, read-only, never prompts) and, when the grant is already denied, says so plainly: no prompt appeared because the browser blocks this site. Browsers without the Permissions API for geolocation (Safari before 16.4) are unaffected and still request as before.
