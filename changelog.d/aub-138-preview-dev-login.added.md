- `[manual]` Added a prod-inert, double-gated `GET /api/auth/dev-login` endpoint that mints a session **without** Google — a workaround so a tester can sign in on any Vercel preview URL (where OAuth's exact-match redirect URIs can't be registered). Fail-closed gating: enabled ONLY when `VERCEL_ENV` is `preview` or `development` (unset/`production`/any other value → 404) AND a Preview-scoped `PREVIEW_LOGIN_SECRET` is set (constant-time compared; 401 without it). Can only ever sign in as a `preview:`-namespaced test user — it returns **403** rather than impersonate any real/OAuth account, so it can't escalate to an existing admin. Reuses the same sealed-cookie primitive and `validateReturnTo` open-redirect guard as the OAuth callback (AUB-138).
