- `[manual]` Typed listing links (AUB-202): a listing now carries up to one link per kind (menu, gluten-free menu, website, reservations, online ordering) in the new `listing_links` table. The add-listing wizard collects all five as optional fields, and the detail page renders them as buttons with a wiki-style "Edit links" dialog for any signed-in user (writes login-gated, rate-limited, and http(s)-only per #90). Legacy `menu_url` rows keep their menu button via a render fallback, typed menu edits supersede (and clear) the legacy column so removals stick, and `pnpm db:backfill:listing-links` idempotently migrates them into `listing_links` (its one-time prod workflow ran and was retired — AUB-221).
