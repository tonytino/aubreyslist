- `[manual]` Added `.github/workflows/post-deploy-smoke.yml`, a post-deploy smoke test that curls the LIVE production URL's `/api/health` and `/about` and fails loudly on a non-200 (AUB-157) — closing the gap where `ci.yml`'s "Production build smoke" only ever tested a locally-built instance on `localhost:3000`. Triggers on a successful production `deployment_status` event, a sparse 6-hourly `schedule` backstop, and `workflow_dispatch`. The production URL comes from the `PRODUCTION_URL` repo variable (falling back to the triggering deployment's own `target_url`, then failing with an explanatory error) rather than defaulting to `SITE_URL`, since per ADR-009 the live site is currently a `*.vercel.app` domain while `SITE_URL` hardcodes the aspirational `aubreyslist.com`. Coordinates with, and does not duplicate, the separate always-on external uptime monitor tracked in AUB-155.
