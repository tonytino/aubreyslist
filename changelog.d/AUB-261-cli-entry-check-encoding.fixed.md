- `[manual]` Fixed the `scripts/` commands silently doing nothing when the repo lives at a path containing a space (or `#`, `?`, non-ASCII). Two places built a file URL by hand instead of encoding it: the direct-invocation guard in `scripts/cli.ts` compared `import.meta.url` against `` `file://${process.argv[1]}` ``, and the alias loader (`scripts/alias-resolve-hook.mjs`) derived its parent directory from `new URL(...).pathname`, which stays percent-encoded. Both now use `node:url` (`pathToFileURL` / `fileURLToPath`), matching what the `.mjs` scripts already did. The failure mode was silent — `pnpm db:seed-admin` exited 0 having done no work — so it is fixed together: the loader failed first, and repairing only the guard would not have made the scripts runnable.
