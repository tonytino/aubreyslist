- `[manual]` CI: a "Migrate preview database" workflow (`.github/workflows/migrate-preview.yml`) applies pending Drizzle migrations to a PR's Vercel **preview** Neon branch (resolved via the Neon API), so schema-changing PRs are testable in preview instead of 500-ing against the unmigrated production-forked branch (AUB-139). Requires a `NEON_API_KEY` repo secret (and optionally `NEON_PROJECT_ID`); skips gracefully when unset.
