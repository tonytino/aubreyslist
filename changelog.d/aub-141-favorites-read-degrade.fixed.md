- `[manual]` The public directory no longer 500s if a favorites read fails: `getFavoriteCounts` (run on every browse render), `getViewerFavoriteIds` (the root prefetch), and `getViewerFavorites` (`/favorites`) now degrade to empty results — reported to Sentry, not silent — instead of throwing. This keeps the core page up when the `favorites` table is briefly unavailable (a fresh/preview DB without the migration, or the deploy window before `migrate.yml` applies the schema). Writes still surface errors to the user.
