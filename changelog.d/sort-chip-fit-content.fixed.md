- `[manual]` The sort and radius chips are now as wide as the option you picked, not as wide as the longest one. A native `<select>` takes its width from its widest `<option>`, so "Near me" sat in a chip stretched to fit "Alphabetical (A–Z)". Both controls now set `field-sizing: content`, which sizes a select to its selected option (Baseline since June 2026: Chrome 123+, Safari 26.2+, Firefox 152+). An older browser keeps the widest-option width, which is cosmetic only. The markup is unchanged: still one labelled native `<select>`, so the platform's own picker and keyboard behaviour stay intact.
