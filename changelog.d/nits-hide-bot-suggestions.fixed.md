- `[manual]` The "Hide bot suggestions" chip (`?bot=false`) now actually hides bot-suggested listings: in addition to reverting filter matching to community-evidence-only (its previous, matching-only effect), it excludes listings whose browse card is driven by a live curator-bot suggestion alone (no community attestation evidence on any visible claim) from the result set — applied in SQL to both the page and the total-count query, so pagination and "showing X of Y" stay honest. Listings with any real community evidence remain visible; the default (`bot=true`) browse is unchanged.
