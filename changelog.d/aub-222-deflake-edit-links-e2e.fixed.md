- `[manual]` Hardened the `edit-listing-links` E2E spec against CI (Neon) latency, reconciling with #293. A framework-initiated mid-save document reload (AUB-223) can discard the save's client-side refetch and server-render the page from a read that raced the still-committing mutation, so a pre-reload DOM assertion is a latency lottery. #293 added a dialog-close wait (which fixes an aria-hidden vacuous pass and covers most runs) but leaves a residual window where the test's own `page.reload()` can still race the mutation/framework reload. Both save-flow tests now combine that dialog-close wait with a DB-side barrier — polling `listings.menu_url` / `listing_links.url` (the server write contract) via new `Seeder.getListingMenuUrl` / `Seeder.getListingLinkUrl` — before any reload or DOM assertion, closing the window. Test-only; the links feature's server writes were always correct.
