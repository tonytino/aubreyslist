- `[manual]` "Near me" now sticks. Once you pick the distance sort and grant location, the browse page restores it on later visits: the opt-in is remembered per device (a flag in `localStorage`, never your coordinates) and only replayed when the browser already holds a geolocation grant, so a remembered preference never opens a permission prompt and never overrides a link that carries its own sort or coordinates. Picking any other sort, or the Reset chip, forgets it. The sort itself still lives in the URL (`?sort=distance&lat=&lng=`), so refresh, back/forward, and sharing are unchanged.
