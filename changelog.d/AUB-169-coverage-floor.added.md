- `[manual]` Added an absolute whole-repo coverage floor (`coverage.thresholds` in `vitest.config.ts`, issue AUB-169) alongside the existing changed-lines-only diff-coverage gate (issue #183): `statements 91% / branches 90% / functions 85% / lines 91%`. Diff coverage alone lets aggregate coverage decay across many individually-80%-compliant PRs; this catches that drift. It is enforced by Vitest itself whenever `--coverage` runs (`pnpm test:coverage`), which in CI is the "Diff coverage" job's "Test with coverage" step (`.github/workflows/ci.yml`) — no new script or dependency. Thresholds sit ~2-3 points below the measured DB-free baseline (93.59% / 92.13% / 87.45% / 93.59%) as deliberate headroom.
