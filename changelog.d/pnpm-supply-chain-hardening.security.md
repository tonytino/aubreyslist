- `[manual]` Hardened install-time supply-chain posture via `pnpm-workspace.yaml`: `minimumReleaseAge: 10080` quarantines newly published versions (including transitive deps) for 7 days before they can be installed — mirroring the existing Dependabot `cooldown` — and `blockExoticSubdeps: true` forbids transitive dependencies from resolving to exotic sources (git/tarball URLs). Build scripts are now an explicit `allowBuilds` allowlist (`@biomejs/biome`, `@parcel/watcher`, `@sentry/cli`, `esbuild`, `lefthook`) rather than pnpm 9's run-everything default.
