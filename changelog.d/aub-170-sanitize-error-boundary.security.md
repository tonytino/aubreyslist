- `[manual]` The root error boundary (`RootErrorBoundary` in `app/routes/__root.tsx`) no longer renders the raw `error.message` to end users in production — it now shows a generic "An unexpected error occurred. Our team has been notified." message. The production/preview distinction comes from a new `isProductionEnvironment()` server-truth check (`app/env.ts`, keyed off `VERCEL_ENV`), exposed to this client component via a root-loader-prefetched query (`app/lib/deployment-env-query.ts`) rather than `import.meta.env.PROD` — Vercel preview deployments are still built in production mode, so that signal alone can't tell preview apart from real production. Dev/preview keep showing the real `error.message` for debugging. The full error is still always forwarded to Sentry via `captureException`, unaffected by this change (AUB-170).
