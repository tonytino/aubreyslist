- `[manual]` "Near me" is now the directory's default order. It anchors on your browser location when you allow it, else on the approximate location of your network connection (from the request headers, city-level, never stored), and when it has neither it degrades to "Recently confirmed" rather than alphabetical. The browse response carries `effectiveSort` and `locationSource` so the page states which of those it did instead of showing one order under another order's name. `DEFAULT_BROWSE_SORT` is now `distance` and `?sort=alpha` is a real, non-default choice that stays in the URL; the new `DISTANCE_FALLBACK_SORT` is the single definition of what near-me degrades to, read by both the SQL `ORDER BY` and the copy. The distance-radius filter follows the same anchor chain (browser reading, then coarse request location, then Denver Union Station), so "Within N mi" now filters from where the sort measures.
