- `[manual]` The `Dependency vulns (osv-scanner)` CI gate now understands the 7-day `minimumReleaseAge` quarantine instead of contradicting it. Previously any newly published advisory failed every open PR for up to a week, because the gate demanded a fix that pnpm is configured to refuse until it is 7 days old — leaving a hand bypass as the only way through. A new zero-dependency wrapper (`.github/scripts/check-osv.mjs`) looks up each fix's npm publish date: a fix still inside the quarantine becomes a deferred warning carrying its unblock date and the build stays green, and it turns into a hard failure by itself once the quarantine lapses. Advisories with no published fix, and anything CVSS Critical, still fail immediately. A new `osv-scanner.toml` holds reviewed, expiring waivers for advisories that will never have a fix.
