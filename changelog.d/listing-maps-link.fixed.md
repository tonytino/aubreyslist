- `[manual]` Fixed the listing "Open in Google Maps" link, which dead-ended because it used the undocumented `maps/place/?q=place_id:…` URL format Google Maps no longer resolves. New listings now store Google's own share link (`googleMapsUri` from Place Details) with the documented Maps URLs API format (`/maps/search/?api=1&query=…&query_place_id=…`) as fallback, and `pnpm db:backfill:maps-urls` (plus the "Backfill production maps URLs" workflow) rewrites existing rows from data already on them — no Places API calls.
