- `[manual]` The preview-only dev-login now has a UI: `GET /api/auth/dev-login` (with no secret) serves a small HTML sign-in form so the `PREVIEW_LOGIN_SECRET` is entered and POSTed in the request body instead of the URL (keeping it out of history/logs), and a preview-only "Dev sign-in" link appears in the header beside "Log in" so a tester can find it — Google OAuth can't complete on a per-deployment preview URL. Both are gated by the same `isPreviewLoginEnabled()` check as the endpoint, so the form 404s and the header link never renders in production. The `?secret=` query form still works for curl/e2e.
